🙋 궁금해요

돈이 드나요?

아니요, 완전 무료예요. 광고도 없어요.

설치해야 하나요?

설치 없이 파일을 더블클릭하면 바로 나와요. 지우고 싶으면 파일만 삭제하면 돼요.

실행할 때 파란 경고창이 떠요!

아직 인증서가 없는 개인 앱이라 Windows SmartScreen이 물어볼 수 있어요. "추가 정보 → 실행"을 누르면 돼요. 소스 코드는 GitHub에 모두 공개되어 있어요.

어떻게 끄나요? 옮기려면요?

트리를 마우스로 끌어서 옮기고, 우클릭하면 메뉴가 나와요. 크기·소리·소원 달기·종료가 모두 거기 있어요.

Mac이나 휴대폰도 되나요?

지금은 Windows만 지원해요. 대신 위의 놀이터는 휴대폰에서도 놀 수 있어요!
